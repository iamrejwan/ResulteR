<h1>📚 RESULTER - Result Viewer</h1>

<p><strong>RESULTER</strong> is a simple and lightweight Flutter mobile application designed for students.<br>
It allows students to quickly fetch and view their results by entering their ID, in a clean and modern interface.</p>

<hr>

<h2>📋 Project Description</h2>

<p>RESULTER connects to the online result portal and retrieves academic results for a specified semester using the ID.</p>

<ul>
  <li>🔎 Search results by ID</li>
  <li>📜 Display results with course details, grades, and CGPA</li>
  <li>📋 Easy copy feature to copy full result</li>
  <li>📱 Modern, smooth UI optimized for mobile</li>
  <li>🔒 Minimal API exposure using obfuscation (future HTTPS recommendation)</li>
</ul>

<hr>

<h2>🚀 Features</h2>

<ul>
  <li>Fetch real-time semester results</li>
  <li>View course title, code, credit, grade, and point</li>
  <li>Modern, clean Flutter UI</li>
  <li>Copy entire result to clipboard easily</li>
  <li>Lightweight APK (&lt;10MB)</li>
</ul>
